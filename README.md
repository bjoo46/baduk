## 좌표 표기

19×19 표준 좌표계. 가로는 `A`–`T` (`I` 제외), 세로는 `1`–`19` (아래가 1).

- **D16** — 좌상귀 4-4 화점
- **Q16** — 우상귀 4-4 화점
- **Q4** — 우하귀 4-4 화점

`I`를 건너뛰는 것은 세로선 1과 숫자 1의 혼동을 피하기 위한 관례입니다.
